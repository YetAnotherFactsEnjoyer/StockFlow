# Source provenance

This StockFlow backend scaffold was generated from the owner's previously uploaded/saved `java-backend-starter.zip` (Java 21, Spring Boot 4.1.1, Gradle, JWT identity, PostgreSQL, Flyway, tests). The saved starter describes itself as derived from the GhostPay identity/JWT foundation, and its `scripts/new_project.py` was run with `--name stockflow --package com.stockflow`.

The user also provided their GitHub URL `https://github.com/YetAnotherFactsEnjoyer/Springboot-Template`, but that live GitHub repository could not be fetched from the generation environment. Accordingly, this ZIP is based on the saved starter copy, **not** independently verified against the latest GitHub commit. No files were copied from `StockFlow-main.zip` into this backend.

Included from the saved starter, with StockFlow-specific renames/configuration: identity, security, error handling, Gradle wrapper, Dockerfile, PostgreSQL Compose, CI tests, V1 user migration.

Changed: project and Java package, application class name, database/issuer names, dedicated host ports, isolated Compose name, documentation, empty modular-monolith feature folders. Removed the one-time template renamer after applying it and removed template-oriented docs.
